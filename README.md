## 🚀 Featured Projects

### 🌊 AquaSense AI
**Intelligent Campus Water Management & Demand Prediction System**

An IoT + AI based water monitoring platform that collects real-time flow telemetry from an **ESP32 with dual YF-S401 flow sensors**, processes the data through a **FastAPI backend**, stores telemetry in **SQLite**, and visualizes the system through a **React + TypeScript dashboard**.

**Highlights**
- Real-time upstream/downstream flow monitoring
- Water-loss detection using differential flow analysis
- Sensor/calibration anomaly detection
- Historical water usage analytics
- Linear Regression based water-demand prediction
- Reservoir supply planning
- REST API based ESP32 → backend communication

**Built with:** ESP32 • FastAPI • Python • SQLite • React • TypeScript • Tailwind CSS • scikit-learn

🔗 [View Project](https://github.com/soorya-117/AquaSense-AI)
